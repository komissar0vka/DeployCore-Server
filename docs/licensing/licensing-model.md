# Модель лицензирования

Этот документ описывает ранний проект. Актуальное предложение для согласования, включая тариф Free, учёт устройств, автономную активацию и отзыв, находится в [архитектуре DeployCore 1.0](../architecture/deploycore-1.0.md#лицензирование).

Планируемый модуль licensing вычисляет права экземпляра и предоставляет их прикладному слою. Редакции Community, Business и Enterprise используют единую модель прав.

Офлайн-активация импортирует файл с версией формата, идентификатором ключа и подписанной полезной нагрузкой. Полезная нагрузка содержит идентификаторы лицензии и экземпляра, редакцию, срок действия, максимальное число устройств и feature flags. Подпись Ed25519 проверяется по встроенному набору открытых ключей. Закрытые ключи хранятся отдельно от продукта. Формат подписи фиксирует точные байты полезной нагрузки.

Контроль квоты выполняется атомарно при регистрации устройств. Для истёкшей лицензии планируется сохранить возможность входа, чтения состояния и импорта обновления. MVP работает без активации. Платежи, сервер активации и применение ограничений находятся за пределами этапа 1.
