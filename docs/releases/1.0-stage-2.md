# DeployCore 1.0 · этап 2

Дашборд показывает состояние устройств, активные и проблемные развёртывания, предупреждения и готовность сервера. Нажатие на проблемное задание открывает его журнал, на версию агента — мониторинг этой версии. Данные поступают из PostgreSQL через действующий API.

- **Устройства.** Список поддерживает поиск, фильтр связи и отзыва, сортировку и страницы. В карточке доступны оборудование, программы с поиском и страницами, события и история развёртываний этого компьютера.
- **Агенты Windows.** Отдельный экран обновляет список каждые 15 секунд. Можно выбрать версию, состояние связи или отзыв ключа. Установка агента и управление токенами остаются отдельным разделом для операционных ролей.
- **Каталог.** Поиск по названию и издателю, сортировка и страницы. Сохраняются утверждение файлов и предпросмотр обнаружения.
- **Развёртывания.** Поиск по пакету и версии, фильтры по состоянию, операции и устройству. Журнал показывает устройство и номер попытки, поддерживает фильтр и переход к более ранним событиям. Кнопка ручного повтора учитывает роль оператора.
- **Профиль.** Каждый пользователь может переключить русский и английский языки, светлую и тёмную темы. Выбор сохраняется в браузере.

В панели доступны рабочие разделы. Отдельные модули карты, отчётов, лицензирования и обновлений появятся после реализации их API.

## Проверки

Прошли 43 теста pytest, Go test и vet, Windows amd64 cross-build, TypeScript/Vite и сверка OpenAPI. В Chromium с тестовым API проверены дашборд, журнал, фильтры, сортировка, клавиатура, мобильный Viewer, RU/EN и обе темы. Изолированный Compose подтвердил совместимость API, фильтры, пагинацию, ограничения ролей и прежний агентский протокол.
