# Матрица приёмки Windows для beta.5

Для каждого прогона укажите сборку ОС, версию Server и агента, профиль TLS, тип доставки MSI, дату, результат и ссылки на обезличенные события агента и Server. Доменные сценарии выполняются в выделенной тестовой OU после согласования владельцем инфраструктуры.

| ОС x64 | Вне домена | В домене с GPO |
| --- | --- | --- |
| Windows 10 | Открыто | Открыто |
| Windows 11 | Открыто | Открыто |
| Windows Server 2019 | Открыто | Открыто |
| Windows Server 2022 | Открыто | Открыто |

Для каждой конфигурации выполните следующие проверки.

1. Установите агент без ручного ввода. Проверьте регистрацию, статус службы, инвентарь, повторный запуск и сохранение идентичности.
2. Обновите старую службу без MSI, затем обновите MSI поверх предыдущей версии. Сверьте UUID, параметры соединения, регистрацию, доверенный CA и сохранение пользовательских файлов. Отдельно проверьте контролируемую ошибку и откат.
3. Проверьте цепочку TLS, неверное имя, просроченный сертификат и переход между двумя доверенными CA. Для домена проверьте доставку корня через GPO.
4. Выполните разрешённые MSI, EXE и Portable. Сверьте журнал, код выхода и обнаружение. Для Portable проверьте сохранение постороннего файла после удаления.
5. Проверьте отказ при неверной подписи, чужом UUID, истёкшем сроке, повторном получении задания и понижении уровня протокола. Проверьте разрыв сети до и после старта и восстановление после перезагрузки.
6. Обновите агенты тестовой группы, подтвердите приостановку при сбое, продолжение после исправления и историю. Сверьте статус устройств.
7. Удалите агент. Проверьте удаление службы, согласованную политику хранения конфигурации и возможность повторного подключения.

Windows-раннер GitHub и моделирование нагрузки фиксируются отдельными результатами. Они не закрывают ячейки матрицы.
