# DeployCore Changelog

## 1.0 · этап 1, надёжность исполнения

- Agent 0.3.5 различает `installed`, `not_installed` и `unknown`. Ошибки чтения реестра сохраняют неопределённость. Недоступность проверки и подтверждённое несовпадение показаны как отдельные причины.
- Добавлены составные правила `all` / `any`, предпросмотр на тестовом устройстве и отдельная проверка после перезагрузки. Журнал агента сохраняет ожидающую проверку и её результат между перезапусками.
- Миграция `0007_detection` сохраняет сведения о запуске и отдельные наблюдения. Agent 0.3.4 обслуживается по прежнему контракту с одиночными правилами.
- Прошли 38 тестов pytest, Go race и vet, кросс-сборка Windows, сборка веб-панели, сценарии Chromium и изолированный Compose. Приёмка на доменной и недоменной Windows остаётся открытой. Матрица проверки приведена в [отчёте этапа 1](docs/releases/1.0-stage-1.md).

## 1.0 · этап 0, проектирование

- Проверен текущий код до `0006_manual_approval`. Подготовлены архитектура Server, Cloud и Update Center, проект лицензирования, план интерфейса и миграций, критерии готовности этапов.
- Изменены только документы. Приёмка на реальной доменной и недоменной Windows остаётся открытой. Подробности и результаты проверок в [отчёте этапа 0](docs/architecture/deploycore-1.0.md).

## 0.5.0 · этап C

## 0.5.0 · этап B

- Миграция `0004_deployment_queue` добавляет задания, цели, попытки и события в PostgreSQL.
- Панель поддерживает установку и удаление в режиме проверки транспорта, выбор устройств, прогресс, историю и управляемую отмену.
- Agent 0.3.3 обменивается заданиями по HTTPS, сохраняет попытку и результат через DPAPI и повторяет доставку без запуска установщиков.
- Прошли pytest, Go race/vet, сборка для Windows, Chromium и изолированный Compose с конкурентной выдачей, восстановлением и отменой.

## 0.5.0 · этап A

- Добавлен каталог программ с версиями x64/x86, метаданными установки и удаления, правилами обнаружения и явным утверждением.
- Файлы MSI/EXE хранятся на отдельном томе. Добавлены потоковая загрузка, проверка свободного места, SHA-256 и локальная проверка Authenticode.
- Миграция `0003_package_catalog` добавляет четыре таблицы каталога. Контракт Windows Agent сохранён.
- Прошли 17 тестов pytest, Chromium и изолированный Compose, включая обновление с `0002_devices`, загрузку и проверку подписанных MSI/EXE и сохранность тома.

## Windows Agent 0.3.2

- Исправлен запуск графического мастера через Windows PowerShell. HTTPS-адрес вводится в отдельное поле.
- Соглашение описывает права службы, инвентаризацию и передачу данных выбранному серверу. Для установки через мастер нужно подтвердить согласие.

## 0.3.1 — стабилизация и улучшение интерфейса

- EXE открывает мастер по двойному щелчку. MSI устанавливает мастер в меню «Пуск». Адрес и регистрационный токен задаются на компьютере.
- Установка и команда `check` проверяют доверие TLS, имя сервера и ожидаемый ответ readiness. Команды в панели копируются по отдельности.
- Дашборд показывает количество компьютеров по статусу, версии агентов, последние события и ошибки. Боковое меню адаптируется к ширине экрана. Добавлены пустые состояния.
- Инвентаризация показывает модель и производителя компьютера, метки и файловые системы томов, MAC-адреса и ранее доступные сведения о CPU, памяти, сети и ПО. Снимки 0.3.0 по-прежнему читаются.
- Добавлены инструкция GPO, сценарий приёмки и проверка Windows MSI, службы и TLS-протокола в CI. Схема PostgreSQL не менялась.
- Проверены 14 тестов FastAPI, Go с детектором гонок, go vet для Linux и Windows, сборка TypeScript/Vite, интерфейс в Chromium и запуск нового изолированного экземпляра Compose. EXE и MSI Windows x64 собраны. Проверены содержимое MSI и SHA-256. Приёмка мастера, установки и GPO на реальной Windows остаётся открытой.
